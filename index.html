Estructura de un Programa

Conceptos básicos para comprender cómo funciona un programa informático.

Entrada

Es la información que el usuario ingresa al programa.
Ejemplo: escribir un nombre en un formulario.

Proceso

Transforma los datos para obtener un resultado.
Ejemplo: calcular una suma automáticamente.

Salida

Es el resultado mostrado por el programa.
Ejemplo: mostrar un mensaje en pantalla.

Palabras Reservadas

Son palabras propias del lenguaje.
Ejemplo: if, else, while.

Programación Orientada a Objetos

Organiza el código en objetos.
Ejemplo: un objeto Auto con color y velocidad.

Propiedades

Describen un objeto.
Ejemplo: color = azul.

Métodos

Acciones de un objeto.
Ejemplo: guardar() o imprimir().

Datos y Tipos de Eventos

Los eventos activan acciones.
Ejemplo: clic en un botón.

Enteros

Números sin decimales.
Ejemplo: 25

Flotantes

Números con decimales.
Ejemplo: 15.75

Textos

Cadenas de caracteres.
Ejemplo: "Hola mundo"

Booleanos

Valores lógicos.
Ejemplo: verdadero o falso.

Entorno de Trabajo

Espacio donde se programa.
Ejemplo: Visual Studio Code.
