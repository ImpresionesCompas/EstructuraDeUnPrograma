Estructura de un Programa

Conceptos básicos para comprender cómo funciona un programa informático.

Entrada

Es la información que el usuario o sistema proporciona para iniciar una tarea dentro del programa.

Proceso

Es el conjunto de operaciones que transforman los datos de entrada para obtener un resultado.

Salida

Es el resultado final que el programa muestra al usuario después de procesar la información.

Palabras Reservadas

Son términos del lenguaje de programación con funciones especiales que no pueden usarse libremente.

Programación Orientada a Objetos

Organiza el código en objetos que contienen datos y funciones para representar elementos reales.

Propiedades

Son características que describen un objeto. Las más comunes son nombre, color, tamaño, posición y estado, ya que permiten identificar cómo es un elemento dentro del programa.

Métodos

Son acciones que realiza un objeto. Algunos métodos comunes son iniciar(), mostrar(), guardar(), eliminar() y actualizar(), que permiten modificar o ejecutar tareas específicas.

Datos y Tipos de Eventos

Los datos guardan información como números o texto. Los eventos más usados son clic, doble clic, movimiento del mouse, pulsación de teclas y carga de página, que activan acciones en el sistema.

Enteros

Son números sin decimales utilizados para contar o identificar cantidades exactas.

Flotantes

Son números con decimales que permiten representar valores más precisos.

Textos

Son cadenas de caracteres que almacenan palabras, frases o símbolos.

Booleanos

Representan valores lógicos con dos posibles estados: verdadero o falso.

Entorno de Trabajo

Es el espacio donde el programador escribe, organiza y prueba su código.
