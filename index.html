Estructura de un Programa

Conceptos básicos para comprender cómo funciona un programa informático.

Entrada

Es la información que el usuario o el sistema introduce para que el programa pueda comenzar a trabajar correctamente.
Ejemplo: escribir un nombre en un formulario.

Proceso

Es la serie de instrucciones internas que transforman la información recibida para generar un resultado útil.
Ejemplo: calcular una suma automáticamente.

Salida

Es el resultado mostrado por el programa y representa la respuesta final del sistema.
Ejemplo: mostrar un mensaje en pantalla.

Palabras Reservadas

Son palabras propias del lenguaje que tienen una función especial dentro del código.
Ejemplo: if, else, while.

Programación Orientada a Objetos

Es una forma de programar que organiza el código en objetos con características y acciones propias.
Ejemplo: un objeto Auto con color, marca y método encender().

Propiedades

Son atributos que describen las características de un objeto dentro del programa.
Ejemplo: color = azul.

Métodos

Son funciones que indican las acciones que un objeto puede realizar.
Ejemplo: guardar() o imprimir().

Datos y Tipos de Eventos

Los datos almacenan información y los eventos responden a acciones del usuario.
Ejemplo: clic en un botón.

Enteros

Números sin decimales usados para cantidades exactas.
Ejemplo: 25

Flotantes

Números con decimales para mayor precisión.
Ejemplo: 15.75

Textos

Son cadenas de caracteres usadas para almacenar palabras o frases.
Ejemplo: "Hola mundo"

Booleanos

Representan valores lógicos verdadero o falso.
Ejemplo: usuarioActivo = true

Entorno de Trabajo

Es el espacio digital donde el programador escribe, organiza y corrige código.
Ejemplo: Visual Studio Code.
