Estructura de un Programa

Conceptos básicos para comprender cómo funciona un programa informático.

Entrada

Es la información que el usuario o el sistema introduce para que el programa pueda comenzar a trabajar con ella de manera correcta.
Ejemplo: escribir un nombre en un formulario.

Proceso

Es la serie de instrucciones internas que transforman la información recibida para generar un resultado más útil dentro del sistema.
Ejemplo: calcular una suma automáticamente después de ingresar dos números.

Salida

Es el resultado mostrado por el programa.
Ejemplo: mostrar un mensaje en pantalla.

Palabras Reservadas

Son palabras propias del lenguaje.
Ejemplo: if, else, while.

Programación Orientada a Objetos

Es una forma de programar que organiza el código en objetos con características y acciones propias para facilitar su reutilización.
Ejemplo: un objeto Auto con color, marca y método encender().

Propiedades

Son los atributos que describen las características de un objeto dentro del programa y permiten diferenciarlo de otros.
Ejemplo: color = azul.

Métodos

Son funciones que indican las acciones que un objeto puede realizar dentro del sistema según su propósito y comportamiento.
Ejemplo: guardar() o imprimir().

Datos y Tipos de Eventos

Los datos almacenan información y los eventos permiten responder a acciones del usuario o del sistema automáticamente en tiempo real.
Ejemplo: clic en un botón.

Enteros

Números sin decimales.
Ejemplo: 25

Flotantes

Números con decimales.
Ejemplo: 15.75

Textos

Cadenas de caracteres.
Ejemplo: "Hola mundo"

Booleanos

Valores lógicos.
Ejemplo: verdadero o falso.

Entorno de Trabajo

Es el espacio digital donde el programador escribe, organiza, ejecuta y corrige el código para desarrollar una aplicación de forma ordenada y eficiente.
Ejemplo: un editor como Visual Studio Code con panel de archivos y consola.
